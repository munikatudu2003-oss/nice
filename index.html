用 OpenClaw 搭跨境电商团队：5 个 AI 员工，跑通全平台矩阵

在 Mac mini 本地部署 OpenClaw 后，我设计了一套多 Agent 协作流水线：选品调研、GEO 内容、Reddit 引流、TikTok 视频都可以自动并行跑完。

👨‍💼 1 个总控 Agent 统一接需求
🤖 4 个执行 Agent 并发作业
🔁 sessions_send 异步穿透协作

01｜5 个核心员工

  • lead（大总管）：唯一对人接口，负责拆解需求和跨节点调度。
  • voc-analyst：抓取评论与竞品信息，提炼用户痛点。
  • geo-optimizer：用 GEO 思维写亚马逊/独立站内容，强调数据与权威引文。
  • reddit-spec：执行 5 周养号 SOP，在高权重帖子下做精准评论引流。
  • tiktok-director：生成 25 宫格 UGC 分镜，并串联生图与成片技能。

02｜协作逻辑：异步状态机流水线

  1. 在飞书 @lead 下达任务。
  2. lead 分发给 voc-analyst，提炼痛点（如承重不足、收纳麻烦）。
  3. geo-optimizer 生成带定量数据与来源引用的 GEO 内容。
  4. reddit-spec 在 Google 高排名老帖下做高质量回复，劫持长尾流量。
  5. tiktok-director 读取痛点，输出分镜并调用技能生成 15 秒视频。
异步分发 并发执行 人工审批

03｜从 0 到 1 飞书配置

步骤 1：工作区隔离

~/.openclaw/
├── openclaw.json
├── skills/
├── workspace-lead/
├── workspace-geo/
├── workspace-reddit/
└── workspace-tiktok/

步骤 2：核心路由配置

{
  "channels": {
    "feishu": {
      "enabled": true,
      "connectionMode": "websocket",
      "dmPolicy": "open"
    }
  },
  "bindings": [
    { "agentId": "lead", "match": { "channel": "feishu", "accountId": "lead" } },
    { "agentId": "geo-optimizer", "match": { "channel": "feishu", "accountId": "geo" } },
    { "agentId": "reddit-spec", "match": { "channel": "feishu", "accountId": "reddit" } },
    { "agentId": "tiktok-director", "match": { "channel": "feishu", "accountId": "tiktok" } }
  ],
  "tools": {
    "agentToAgent": {
      "enabled": true,
      "allow": ["lead", "geo-optimizer", "reddit-spec", "tiktok-director"]
    }
  }
}

步骤 3：写入人设与纪律

把各 Agent 的 SOUL.md 与 AGENTS.md 配好。特别是 lead 必须只做调度、禁止亲自执行底层任务。

最后安装全局技能库（如 nano-banana-pro、seedance2.0），执行 openclaw gateway restart。

04｜常见问题结论

  • 目录结构：必须物理隔离，避免上下文污染。
  • 组织方式：优先按职能设计 Agent，再做平台适配。
  • 模型分级：决策层用强模型，执行层用高性价比模型。
  • 飞书发布：变更后需创建新版本并发布，才会生效。
  • 机器人互艾特：用 sessions_send 走暗线，群消息做明线同步。
  • 技能层级：公共技能放全局，私有技能放专属 workspace。
